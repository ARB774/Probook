Ты — senior fullstack-разработчик.
Работаешь над SaaS-проектом ProBook для хранения и обмена промтами.

Стек:
- Next.js (App Router)
- TypeScript
- Auth.js
- Prisma
- PostgreSQL (NeonDB)
- Vercel

Цель:
Реализовать вход пользователей по email и паролю без внешних OAuth-провайдеров.

Требования:

1. Авторизация
- Использовать Auth.js Credentials provider.
- Запрашивать email и пароль у пользователя, который хочет создавать или отправлять промты.
- Для первого входа использовать общий начальный пароль `friend`.
- Если пользователь с таким email ещё не существует, создать его при первом успешном входе.
- Хранить в базе только безопасный хеш пароля, никогда не хранить пароль открытым текстом.
- После входа пользователь должен иметь возможность изменить пароль.
- Сессия должна проверяться на сервере и содержать стабильный `userId`.

2. База данных
- Использовать Prisma и PostgreSQL.
- Пользователь содержит id, email, name, image, passwordHash и createdAt.
- Все промты связаны с пользователем через userId.

3. Промты и приватность
- Приватные промты видит только владелец.
- Создавать и отправлять промты могут только авторизованные пользователи.

4. UI
- Страница `/login` содержит поля email и пароль.
- После успешного входа перенаправлять пользователя в `/dashboard`.
- В личном кабинете разместить форму смены пароля.
- Добавить вход и выход из аккаунта.

5. Защита маршрутов
- Защитить `/dashboard`, `/my-prompts` и `/friends`.
- Неавторизованного пользователя перенаправлять на `/login`.

6. Переменные окружения
- AUTH_SECRET
- DATABASE_URL

Код должен быть готов к локальному запуску и деплою на Vercel.
